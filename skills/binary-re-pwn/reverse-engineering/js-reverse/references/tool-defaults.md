# Tool Defaults

- `js-reverse_list_network_requests`: look at the first page of default results first, paginate only if insufficient
- `js-reverse_search_in_sources`: default `excludeMinified=true`
- `js-reverse_get_script_source`: read only small snippets; for a full source dump, prefer pairing with `js-reverse_save_script_source`
- `js-reverse_break_on_xhr`: only supply a URL fragment that reliably matches
- `js-reverse_get_paused_info`: by default look at `frameIndex=0` first
